# Cinthia Terceros — Personal Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript. No frameworks or paid services needed.

## Preview locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish for free using GitHub Pages

1. Log into GitHub as `ferchitp`.
2. Create a **public** repository named `ferchitp.github.io` (if available).
3. Upload **all four website files** (`index.html`, `style.css`, `script.js`, `resume.pdf`) to the root of that repository. `README.md` is optional.
4. Open repository **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Once GitHub reports the deployment is ready, visit `https://ferchitp.github.io/`.

You can alternatively publish from a repository with a different name; the URL would typically be `https://ferchitp.github.io/repository-name/`.

## Before sharing

- Confirm that project descriptions, current roles, and links are accurate.
- The `resume.pdf` file is public when deployed. Remove it or replace it if you don't want your phone number or email published.
- If you edit your resume, replace `resume.pdf` and republish.
- Add actual project screenshots and GitHub repo links later if you wish.
